# Secretary Dashboard

**비서 업무 지원용 통합 대시보드 시스템**

🌐 **Live Demo:** https://secretary-test-five.vercel.app/

## 📌 주요 페이지

- **📊 대시보드** (dashboard.html) - 주간 일정, 할 일, 프로젝트, 매출 요약
- **📈 매출 현황** (chart.html) - 월별 추이 및 제품별 판매량 분석  
- **📋 사이트 분석** (report.html) - SubTrackr.kr 웹사이트 상세 분석

## 🎨 특징

- ✨ 글래스모피즘 디자인
- 🌓 다크/라이트 모드 
- 📱 반응형 레이아웃
- 📊 Canvas 기반 차트 (외부 라이브러리 없음)
- 💾 localStorage 기반 상태 저장

## 🛠️ 기술 스택

- HTML5, CSS3, Vanilla JavaScript
- Canvas API
- Git, GitHub, Vercel
